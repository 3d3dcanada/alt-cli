Alt 0.6 adds a complete practice repair workflow, tool instructions matched to
the selected focus, clearer check setup, better bounded retrieval and tested
stream/disconnect recovery. Package updates preserve a pre-upgrade state backup.

Download `alt-0.6.0-linux-x86_64.tar.gz` and its checksum. This is a Linux x86_64
beta; the frontend needs glibc 2.30+. Python 3 is required for installation and
the practice checks. Models and inference runtimes are chosen separately in Alt.

Verify the archive's GitHub attestation using the accompanying Sigstore bundle:

```bash
gh attestation verify alt-0.6.0-linux-x86_64.tar.gz \
  --repo 3d3dcanada/alt-cli \
  --bundle alt-0.6.0-linux-x86_64.tar.gz.sigstore.jsonl \
  --signer-workflow 3d3dcanada/alt-cli/.github/workflows/publish.yml \
  --source-ref refs/tags/v0.6.0-beta.1
sha256sum -c alt-0.6.0-linux-x86_64.tar.gz.sha256
tar -xzf alt-0.6.0-linux-x86_64.tar.gz
cd alt-0.6.0-linux-x86_64
bash install.sh
~/.local/bin/alt
```

Start with **Try a practice project** on Home. The included `test-my-pc.py`
records build/hardware results; add `--live` only after selecting an uncensored
model. Nothing is uploaded automatically.

The attached release-gate report covers the exact package and prior-version
recovery. Review the repository's implementation report for model scores and
remaining acceptance gates. Physical GTX 1070 and human beginner qualification
remain outstanding; this beta does not promise arbitrary task success.
