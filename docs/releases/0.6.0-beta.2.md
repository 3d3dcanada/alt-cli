Alt beta 2 includes the compact small-model harness and completes the cloud-side
PC preparation work. It adds live inference stages and remaining allowances,
confirmed finite allowance additions, explicit allocation updates for saved
tasks, and actual failed-case feedback for repeated repair failures.

The packaged `test-my-pc.py` now creates a disposable practice project, asks your
selected uncensored model for a repair, checks four cases independently, tests
follow-up/cancellation/resume, then undoes the edits. It preserves normal Alt
settings and reuses weight paths. Reports separate native transport from model
correctness. See the included `docs/PC_TESTING.md`.

Download `alt-0.6.0-linux-x86_64.tar.gz`, its checksum and Sigstore bundle. Linux
x86_64 and Python 3.8+ are required; no Rust compiler is needed. Models and
runtime binaries are selected separately. Verify and install:

```bash
gh attestation verify alt-0.6.0-linux-x86_64.tar.gz \
  --repo 3d3dcanada/alt-cli \
  --bundle alt-0.6.0-linux-x86_64.tar.gz.sigstore.jsonl \
  --signer-workflow 3d3dcanada/alt-cli/.github/workflows/publish.yml \
  --source-ref refs/tags/v0.6.0-beta.2
sha256sum -c alt-0.6.0-linux-x86_64.tar.gz.sha256
tar -xzf alt-0.6.0-linux-x86_64.tar.gz
cd alt-0.6.0-linux-x86_64
bash install.sh
~/.local/bin/alt
```

The TUI header and `alt build-info` identify beta 2. `alt --version` keeps the
underlying package version, 0.6.0. Start with **Try a practice project**, or run
the recorder after selecting your own model:

```bash
python3 test-my-pc.py --alt "$HOME/.local/bin/alt" --live --repair-only
```

Cloud application checks include 123 Rust tests, both provider adapters,
twelve-turn Git project journeys with uncommitted changes, real narrow-terminal
allowance/reconnect tests, sixty streamed recovery scenarios, and portable
installation/upgrade/rollback gates. Exact package and workflow-identity
attestation results accompany this release. Fresh live model outcomes and
earlier failures are retained in the compatibility/evidence documents. MiMo 9B
and Josiefied 7B Q4 each passed the complete practice repair/recovery journey.
An initial Rust trial exposed a missing cloud toolchain environment; its retained
source also failed a separately configured boundary check. The runner now checks
language tools before spending model allowances. The compatibility record retains
the separate infrastructure requalification and its exact outcomes.
With language tools configured, the fresh Rust trial still failed independent
acceptance and reached its deadline. That task/model configuration is unqualified.

This remains a supervised beta: model success varies by artifact and task.
Physical GTX 1070 memory/speed and human beginner usability require local
testing. No new model weights were trained or automatic quality preset promoted.
