Compact mode changes the source packet and edit schema. It does not rewrite a
user's goal, change their model, weaken checks or interpret model prose as commands.
Both compact formats retain native file discovery, search, memory, skills,
evidence, named checks and the Full-access terminal. Creation, deletion,
checkpoint review and undo use the same authoritative project journal.

Project database version 4 adds short edit-handle lookup records. Full task, path,
SHA256 and UTF-8 range checks remain in the database. Migration first makes a
consistent version-3 backup; old `v1:` handles remain usable for their original
unchanged source. Older Alt builds reject version-4 state. Restore the pre-upgrade
backup when rolling back to an older executable.
