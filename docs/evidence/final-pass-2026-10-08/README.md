# Final-pass evidence

This collection supports the [delivery report](../../FINAL_PASS_DELIVERY.md).
The approved work is implemented; model quality, hardware and human acceptance
remain separate measurements. The earlier [beta 3 audit](../final-audit-2026-10-08/)
is preserved unchanged.

| Directory | What it measures |
| --- | --- |
| `software/` | Rust, Python/training/controller checks, source identity, dependency audit, portable build and a real CLI contract/recovery workflow. |
| `tui/` | Implementation-stage terminal checks; `final-debug/` binds the complete final debug journeys to one immutable executable. |
| `protocols/` | Actual Alt/Goose adapters with weight-free provider fixtures, compact tools, native host-result use, skills/browser, candidates and stream recovery. |
| `runtime/` | Exact uncensored Josiefied 7B Q4 owned-runtime loading, bounded generation and cleanup on CPU. |
| `portable-stress/` | Thirty soak rounds and thirty keyboard-pressure journeys using the exact portable executable. |
| `delivery-candidate/` | Archive integrity, separate research binding, Linux compatibility, actual beta 3 migration, aged-state backup/rollback and portable recovery PTYs. |
| `qualification/` | Frozen model comparisons, all baseline/candidate pilot outcomes, oracle controls, complete planned-slot accounting and persistent workspace measurements. |

Individual receipts name their actual tested source/binary and scope. The final
debug and portable executables share application source SHA-256
`662fd9f11392d39d05d6cea1185c8652830af4579cc3e34b248a3fccf782ecb1`.
The portable executable has SHA-256
`54b0cf02702df83afa96c3c31b5905e2c5311d787b9400f7ac9ac745e0486e51`.
Later test-helper, workflow and evidence commits do not change those application
inputs. Exact executable bytes, weights and large disposable state remain outside
this text-evidence collection; their exclusion is explicit in the relevant ledger.

Failed attempts are retained alongside corrections and reruns. Missing observations
remain missing. A fixture pass, normal process exit or successful model response
does not substitute for an independent behavioral result. The complete final
holdout matrix, physical GTX 1070 measurements, novice sessions and trained weights
are not represented as completed by these records.
